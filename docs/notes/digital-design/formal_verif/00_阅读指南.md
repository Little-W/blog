# 阅读指南

本手册从形式验证原理开始，依次介绍 VC Formal 环境、SVA、通用命令及专用应用。软件文档基线为 **X-2025.06-SP1**，手册修订为 **1.3**。短条目用汇总表比较，使用条件和原理在表后展开；含竖线的语法放在代码块中，完整案例源码直接放在各篇正文。

## 1. 内容组织

| 阅读阶段 | 内容 | 建议目标 |
| --- | --- | --- |
| 原理与模型 | 形式验证、平台、工程与结果 | 理解证明在什么前提下成立 |
| 语言与操作 | SVA、通用命令 | 独立建立一个完整验证工程 |
| 专用应用 | FPV 至 FLP / LPC | 按具体问题选择输入、目标和流程 |
| 查询与进阶 | 集合、AIP、分解、调试和验收 | 审查范围、分析困难和保存证据 |

第一次使用时，先读原理、平台和 SVA，再完成计数器正确版与错误版的对照。已有仿真经验的读者应重点复核 SVA 采样、历史值和复位处理，而不是直接把仿真激励变成形式假设。SoC 集成场景可在通用基础之后按需阅读 CC、FRV、FXP 和低功耗章节。

## 3. 代码与语法的读法

标有“保存为”的代码框给出完整文件内容，连同文件列表、绑定文件和 Tcl 运行步骤可直接组成对应案例。全书 16 篇文章包含 81 处完整源码框，覆盖 58 份源码和配置；同一案例在不同独立文章中出现时，必要代码重复列出，便于单篇阅读。独立工程目录只是可编辑副本，不是阅读正文的前置条件。

命令的“语法”使用尖括号表示应替换参数、方括号表示可选项、竖线表示可选值。它不是待原样执行的脚本；随后给出的示例才是具体调用形式。SVA 运算符的竖线则是语言本身的一部分，不能删掉或加反斜杠。所有含这类字符的完整语法均保留在代码块中。

## 4. 资料基线和验证状态

命令解释依据所提供的 **VC Formal User Guide**（1,168 页）及 **VC Formal Quick Reference Guide**（34 页），各条目保留来源页码。两份文件都对应 X-2025.06-SP1，但存在少数命令名称或参数拼写差异；相应条目说明采用哪一种定义及其限制。UG 将部分命令的完整参数转交给 VC Static Platform 或 DPV 专用手册时，本书只解释已提供资料中能够核实的用法，不自行补造参数。

当前环境没有可授权执行的 VC Formal，**没有运行工具编译或形式证明**。本文的预期结果、反例分析与代码检查不能替代真实工具报告。需要寄存器规格、SFF/FDB、HECTOR 包装或 UPF 的专用流程保留明确的配置要求；配套 FPV 练习不冒充相应原生应用的证明。
