# 质量检查与版本说明

## 1. 本版范围

手册修订 1.3 以所提供的 X-2025.06-SP1 User Guide 和 Quick Reference Guide 为资料基线。正文包含基础、环境、SVA、12 类应用、设计查询、分解证明、调试及验收文章，并另提供集中命令参考。命令条目按用法区分，共 200 项；同名命令在不同应用中具有不同选项时分别说明。

短条目使用汇总表，详细定义和限制在表后展开。命令名称、参数和 SVA 代码保持原字符；含竖线的语法不放入表格。正文保留 81 处完整源码框，覆盖 58 份源码和配置，独立工程文件与正文通过脚本校对。

## 2. 检查层次

| 检查 | 能确认什么 | 不能确认什么 |
| --- | --- | --- |
| 资料对照 | 条目所依据的语法、说明和页码 | 安装版本未记录的行为 |
| 文件与链接 | 文件存在、相对路径和源码引用完整 | 外部许可证与项目数据可用 |
| 代码结构 | 源码块一致、Tcl 括号结构完整 | VC Formal 接受全部语法或证明成功 |
| 表格与 HTML | 表格列数和代码字符不受转义破坏 | 所有第三方 Markdown 阅读器行为相同 |
| PDF 抽查 | 抽查页面的分页、字体、表格和代码显示 | 未抽查页面的所有视觉细节 |

静态检查记录保存在 `脚本与工具/发布检查记录.json`，源码校验值保存在 `脚本与工具/案例源码校验值_SHA256.json`。它们记录实际检查结果，不用“通过”一词替代形式证明。

## 3. 重要修正

AEP 状态机锁定检查不包含在 `-aep all` 中；VHDL 总线检查使用正确的形式变量名称；死锁与活锁综合检查按状态机生成。FXP 分别说明注入来源与观察位置。FRV 使用语法定义中的复数参数名称，并保留与 UG 示例拼写不同的说明。FTA 配置明确父任务，低功耗钳位命令及其选项不与其他连通性命令混用。

共享计数器检查器增加了普通递增断言，补足原先只有范围、保持和回绕的说明。批处理示例中的环境检查改为显式等待完成。专用流程仍保留其真实输入要求，不提供伪造的寄存器规格、故障数据库、HECTOR 包装或电源意图。

## 4. 仍需在本地执行的验证

当前制作环境没有可授权运行的 VC Formal。**本次没有执行 VC Formal 编译、属性求解或专用应用分析，也没有产生真实的 Proven、Falsified 或 Covered 报告。** 代码中的预期现象用于教学，不能作为芯片项目的验证证据。

安装环境需要核对工具版本、许可证、前端参数、复位序列、对象解析、目标数量与实际状态。UG 对部分平台命令和 DPV 高级流程只给出示例，并将完整定义转交给未提供的专用手册；本书没有把这些条目扩写成无来源支持的参数全集。

## 5. 构建与维护

修改独立源码后，先同步正文源码，再执行发布检查和构建。修改命令条目时，应同时更新所在文章、集中命令参考和命令资料索引中的来源记录。原始输入压缩包和参考 PDF 未被覆盖。

```bash
python3 脚本与工具/sync_inline_sources.py --update
python3 脚本与工具/validate_publication.py --source-only
python3 脚本与工具/build_pdf.py
python3 脚本与工具/validate_publication.py
```
