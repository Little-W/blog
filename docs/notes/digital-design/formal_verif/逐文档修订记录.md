## 命令资料范围

正文和集中参考共整理 200 个命令及应用用法条目；同一个命令在不同应用中需要区分的调用方式单独说明。条目不是对 1,168 页 UG 的所有文字逐页翻译。UG 本身没有给出完整语法的条目，仅整理其出现的形式；需要额外的 VC Static Platform 或 DPV 专用手册才能进一步补齐的范围，在相应条目中说明。

## 保留与删除

保留全部 81 处完整源码框和 58 份对应源码；原有插图继续提供三种格式。删除旧版格式检查器、旧转换记录、旧构建产物和未纳入本轮审核的历史笔记副本，避免读者同时打开互相矛盾的版本。原始输入压缩包未修改。
