# VC Formal 中文形式验证手册

文档基线：X-2025.06-SP1；手册修订：1.3；修订日期：2026-10-17。

从[阅读指南](00_阅读指南.md)进入分篇教程，或直接打开[PDF 合订本](VC_Formal_中文手册_合订本.pdf)、[Markdown 合订本](合订本.md)和[离线 HTML](VC_Formal_中文手册_离线阅读版.html)。按命令检索时使用[命令逐项详解](命令逐项详解.md)。

本版把零散短条目整理为汇总表，并在表后解释条件与原理；命令逐项列出语法、参数、使用方式、示例和来源页码。含竖线的 SVA 运算符和参数备选写法只放在代码块里，不对源码加入表格转义。

完整案例仍在文章正文中；`案例工程/` 是相同内容的可编辑副本。修改源码后，可运行以下脚本同步并检查文内代码：

```bash
python3 脚本与工具/sync_inline_sources.py --update
python3 脚本与工具/validate_publication.py
python3 脚本与工具/build_pdf.py
```

构建需要 Python、Pandoc、XeLaTeX 及相应中文字体。这里的检查是离线文件与排版检查，不是 VC Formal 编译或形式证明。详细范围见[质量检查与版本说明](质量检查与版本说明.md)和[逐文档修订记录](逐文档修订记录.md)。
